# PKG-package decisions (a zip of a release build for a plain file upload)

## 2026-11-04 PKG-package: npm run package writes a zip of a release build for a file upload to an Apache host
Decision: `npm run package` runs a release build into `site/dist-package` (OUT_DIR, ignored by git) for the address given by `SITE_URL` and `BASE_PATH`, then `scripts/package.mjs`, which writes `reports/package/<folder>-<commit>.zip`. The zip holds one top folder named after the base (`mutation-game/` for `/mutation-game/`), with `deploy/apache/htaccess` as its `.htaccess` (index file, no directory listings, JavaScript, font and JSON types, compression, `no-cache` on pages, `nosniff`) and `deploy/apache/astro.htaccess` as `_astro/.htaccess` (a one-year immutable cache for the hashed files). Every directive is inside IfModule, so a host without a module ignores the block. Entries carry Unix permissions 0644 and 0755 and the commit's date. The script refuses to package when SITE_URL is unset, when index.html is missing or loads its assets under another base, or when the build holds the open-items page (a preview build). Node built-ins only (zlib deflate and crc32); no dependency is added. Tested by `site/tests/unit/package.test.ts`.
What the specification left open: SPEC 7.8 says that serving the site from a subdirectory "needs one rebuild with another BASE_PATH" and names no command or server configuration. The owner asked for a package for practicallyzen.com, uploaded as files to a web host (DECISIONS.md, "OWNER: the site's own address").
Checks on the first package (commit 106ccc7, SITE_URL=https://practicallyzen.com, BASE_PATH=/mutation-game/): the release build wrote 89 pages; the link check found 3855 internal links and 0 problems; `unzip -t` found no errors; the unpacked folder equals the build plus the two .htaccess files; served by a plain static file server under /mutation-game/ from the unpacked zip, basepath.spec.ts (with its base set to /mutation-game/) and nojs.spec.ts passed, 286 of 286.
Reason: the owner's request of 4 November 2026.
