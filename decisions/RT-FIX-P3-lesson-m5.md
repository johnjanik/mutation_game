## 2026-10-17 RT-FIX-P3-lesson-m5: where the regression tests live
Decision: the regression tests of this cluster are in `site/tests/e2e/M5.spec.ts`, in a `describe('regressions')` block at its end, and not in `site/tests/unit/content-*.test.ts` as RT-FIX 5.3 suggests for a lesson's text. Deviation, on the orchestrator's instruction to edit only `m5-weyl.mdx` and `M5.spec.ts`. Consequences: (1) `site/src/lib/golden.ts` imports the golden JSON without the import attribute that Playwright's loader needs, so the number-word cases read the parsed golden file through a small dotted-path walker (`goldenAt`) in place of `resolveGoldenPath`; the paths and values are those of the reproducer. (2) The script reproducer of P3-RT-08-08 printed captions and asserted nothing; its test asserts that each caption differs from the observed one and states its result (a pattern per caption, with the golden value where the result has one), and that the first figure's caption is one sentence. (3) The reproducer of P3-RT-09-02 asserted that the counterexamples do not exist, which can never pass; its test keeps both computations with the values the reproducer observed (the wave on the square still running after 1000 rounds with every firing legal; the one-way road firing only `1,0` and `1,1`) and asserts the finding's expected instead: the sentences that state F6 and F8, in the beats and in the Seen box, carry the finite-type hypothesis. (4) The reproducer of P3-RT-13-07 read the figure of each tool with `querySelector('figure')`; its test reads it by role (`getByRole('figure')`) under the `data-tool` hook, with the same pattern and the same expected empty list. Only the cases of this lesson are adopted; the cases of M1 to M4, of M2, M3 and of the open-problem page stay with their lessons.
