## 2026-10-10 P0-A5: undo, redo, scrub and reset announcements; one move
Decision: Undo announces `Undid move k. Populations now ...` (the position after undoing). Redo announces the move template of the move put back (`Mutated city 1. Populations now minus 1, 0. Move 1.`). Scrubbing to an earlier position announces the undo template for the earliest undone move, to a later one the move template of the last move re-applied; a burst of either coalesces in the announcer. Reset announces `Undid move 1. Populations now 1, 0.` on the index page when at least one move was applied, and nothing when the cursor was already at the start. Undo, redo and reset with nothing to do announce nothing. Pluralisation: "Game over after 1 move." and "Played 1 move to the end."; every other count takes "moves". The announcer writes 500 ms after the last call of a burst (a trailing window), so a single move is announced once, half a second after it is made; the same text twice is cleared and set again 50 ms later. What the specification left open: these cases (A-4 gives the templates only). Reason: the plan (instruction 5.7); SPEC fixes no wording at one move.

## 2026-10-10 P0-A5: size rule and the reserved box
Decision: the board's grid unit is computed in CSS from the width of the figure, which is an inline-size container: `--u: min(64px, round(down, (100cqw - 16px) / k, 1px))` (without the `round()` floor where the browser lacks it); the board's box is `k·u` by `rows·u` plus 8 pixels of padding, and each node button is a square of `min(44px, u)` centred on the node. The island root has a fixed height in CSS (board, a 108-pixel History block, a 24-pixel line for the noscript note, two 12-pixel gaps), so hydration changes no size.
