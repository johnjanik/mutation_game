## 2026-10-10 P0-A6: what fails a route besides its size
Decision: a route whose response is not HTTP 200 is an `ERROR` and fails the run (`route answered <status>`), because an error page fetches no script and would pass every limit at 0 kB; the one exception is the route `/404` (built from `404.html`), for which 200 and 404 are both accepted. A script request to another origin is an `ERROR` (`external script`, SPEC 7.8 "No third-party script at runtime"), and a script URL with no file in the built directory is an `ERROR`, never counted as zero. Scripts are collected from the browser context's `request` event, by `resourceType()` equal to `script` or by a pathname ending in `.js` or `.mjs` (the union), deduplicated per route; a chunk shared between routes counts on every route. Sizes are `zlib.gzipSync(file, { level: 9 }).length` of the file in the built directory, never a transfer size. After `networkidle` the script waits until no request has started for 1 second (at most 15 seconds), for `client:idle` and `client:visible` islands; it never touches the page. What the specification left open: these failure cases. Default used: none. Reason: honest exit codes (P0-A6 instruction 1).

## 2026-10-10 P0-A6: verify.mjs
Decision: `npm run verify` spawns the interpreter named by the environment variable `PYTHON` when it is set and non-empty, else `python3`, as `<python> -u reference/verify.py <tmp>/golden_regen.json` with the working directory at the repository root, streaming the oracle's output; the temporary directory comes from `fs.mkdtempSync` under `os.tmpdir()`, and the script refuses an output path under `reference/` before spawning. It prints the oracle's summary line, then compares bytes with `reference/golden_data.json`. When the bytes differ it compares the two files as parsed JSON in Python (exact integers, where `JSON.parse` would round above 2^53), prints whether they are equal as parsed and, if not, at most twenty differing paths. On any failure (oracle exit status, missing summary, failed checks, different bytes) the temporary file is kept and its path printed, and nothing is copied into the repository. Run on 2026-10-10 in this container with Python 3.13.16: `6649 checks passed, 0 failed, 154.5s`, byte for byte identical (455014 bytes); the three hashes of CONTRACTS.md 9 unchanged. What the specification left open: the interpreter variable and the retention rule. Default used: none. Reason: SPEC 5.7 and the plan (P0-A6 instruction 5.2).
