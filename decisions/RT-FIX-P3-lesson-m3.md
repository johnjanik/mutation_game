## 2026-10-17 RT-FIX-P3-lesson-m3: how M3 quotes Donnelly and Eriksson's theorem
Decision: beat 7 reads "a connected board with roads both ways is of finite type exactly when its numbers game ends from some start with a positive number and no negative one [DE08] (Theorem 2.1)". This is SOURCES.md's record of the theorem ("a connected integer-weighted graph has a terminating game from some nonzero dominant start exactly when it is a Dynkin diagram of finite type") in the site's words: the integer-weighted graphs of [DE08] carry an amplitude in each direction of every edge, so they are the boards with roads both ways of SPEC 2.11 (on the board with one road of `one_way_counterexample` the game from (1, 0) ends after two moves, and that board is not of finite type); [DE08] fires positive numbers with a = lambda (SPEC 2.9), so a dominant start is one with no negative number (Appendix C), and a nonzero one has a positive number. What the specification left open: the wording (SPEC 3 M3 beat 7 prescribes none). Reason: finding P3-RT-09-01.
