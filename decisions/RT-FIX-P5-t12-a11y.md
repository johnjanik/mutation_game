## 2026-10-25 RT-FIX-P5-t12-a11y: the string viewer's board box is as wide as the figure (P5-RT-05-01)
Decision: on T12 the board's box of SPEC 6.1 is the figure, as for every other tool ("2026-10-10 P0-A5: size rule and the reserved box"): the string viewer's `.board-host` runs over its panel's padding and border (12 and 1 pixels each side, `margin-inline: -13px`) and is itself the inline-size container from which Board.svelte reads its grid unit, so that W is the viewport width below 400 pixels (43 on seven columns and 38 on eight at 320; 43 on eight at 360). The panels keep their own container for the 600-pixel layout of the matrices. This holds at every width, so the unit is never read from a box narrower than the figure. What the specification left open: 6.1 [D] defines W as "the width of the board's box" and fixes it below 400 pixels only. Default used: none. Reason: P5-RT-05-01; the panel's padding made the panel the box.

## 2026-10-25 RT-FIX-P5-t12-a11y: a scroll box keeps the focus when its panel is drawn again (P5-RT-05-02)
Decision: each drawing step of T12 (runSteps) notes the scroll box of the figure that has the focus (`role="group"`, `tabindex="0"`), by the data-out of its MatrixView or orbit drawing, and when the step leaves the focus on `<body>` it gives it to the box with that data-out drawn in its place (the server's box moved into the live panel, then the live MatrixView's box). Only scroll boxes are noted: before hydration they are the only tab stops of the server's markup, every control being disabled (4.0, 7.4). What the specification left open: 7.5 A-1 (WCAG 2.4.3) names no focus target when an element is replaced. Default used: none. Reason: P5-RT-05-02, the expected of the finding ("the focus stays on the box the reader is on, or on its live replacement").

## 2026-10-25 RT-FIX-P5-t12-a11y: which replies of the worker are announced (P5-RT-05-03)
Decision: when a relation pick is announced as "checked in the background" (its verdict is not known on the main thread), T12 keeps that representation and the pick's announcer; the worker's list for it then announces the relation sentence with its verdict ("...: the two sides are equal." or "not equal."). A list that arrives after a board or node pick, or after a link, is not announced: the pick sentence (which already says whether the relations hold or fail) is announced then, and the announcer of `site/src/lib/a11y.ts` keeps only the last text given within 500 ms, so a second announcement would often replace it; for the same reason the move to the first failing relation (failingDefault, C5 to C8 node n) is not announced. A failure of the worker is shown ("not checked" and the line below it) but not announced: announcing it (with a longer selector of the focus rule, dropped at the same time) cost 70 bytes of the shared limit of /tools/rep/ (below). What the specification left open: 4.0 "a polite live region announces each result" does not say which results of a background computation are announced, nor how two results within the coalescing time of A-4 are joined. Default used: none. Reason: P5-RT-05-03 and the 90 kB limit of /tools/rep/ (7.6, never raised): 89757 bytes at the base of this branch, 89905 with this branch (148 bytes for this rule and the focus rule of P5-RT-05-02), and the content fix of the round adds about 72 more (89830 at its own base, by the coordinator's measure), which leaves about 20 bytes after both.

## 2026-10-25 RT-FIX-P5-t12-a11y: the figure check of the run without JavaScript reads T12's orbit drawing and matrices (P5-RT-06-01)
Decision: `toolReport` in `site/tests/e2e/nojs.spec.ts` also lists the parts of a root's figure without their content, and `figureProblems` rejects a root with any: an orbit drawing (`data-out="orbit-graph"`) must hold `data-positions` vertices and at least one edge into each vertex below layer 0, or, when it is not drawn (above 300 positions), layer counts that add up to `data-positions`; a matrix (`data-format`, `data-rows`, `data-cols`) must hold every cell of a grid, and a value cell in each row of a list (or its one row "no nonzero entries"). This extends the readings "2026-10-17 RT-FIX-P3-test-integrity: the default figure of the run without JavaScript" and "2026-10-24 RT-FIX-P4-tool-t10: the default figure of a canvas tool in nojs.spec.ts" to T12. What the specification left open: 7.4 asks that "every default figure" be present and names no predicate. Default used: none. Reason: P5-RT-06-01; a T12 root was accepted as "board" through its string viewer alone.
