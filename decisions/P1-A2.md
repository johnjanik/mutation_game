## 2026-10-10 P1-A2: URL form details
Decision: (1) Key order `z g v m c s w x t r j e y k q d`, `z=1` always first, a key only when its field is present; `w=` is written for an empty move list that is present. (2) Prefix: `'b2'` and `'b2.'` both give `b2.`; empty or absent gives bare keys. (3) Only `& = # % +` and space are escaped (percent-encoded); commas, semicolons, dots, `~`, `^`, colons and `@` stay readable. (4) A key given twice (after the prefix) does not parse (rule 1). (5) `q` is a code among `hh he hf ef serre-e serre-f`, a colon and exactly two labels separated by a comma; `j` is `coxeter` or `xyz:a,b,c` with three distinct integers from 1 to n, optionally `@` and three integers (a minus sign allowed). (6) `lambda` (`d`) holds safe integers only; a larger entry fails rule 1. (7) Rule 4 counts digits without the sign (40 pass, 41 fail). (8) Board names in `g` match `[A-Za-z0-9~^()_-]+` before `boardFromName` is asked; anything it does not know fails rule 2. (9) The `@` part of `g` is kept when it parses as n pairs of numbers and dropped otherwise, never a notice. What the specification left open: these details. Reason: the instruction (5.2, 5.3).

## 2026-10-10 P1-A2: the worker's wire format and EngineApi

## 2026-10-10 P1-A2: History API
Decision: `registerInstance(instanceId, defaults, onPopState?, initial?)` throws `Error("duplicate instance id <id>")` on a second registration; `defaults` is the author's state (links write only what differs from it) and `initial` the state shown now; registering writes nothing. `stateChanged` ignores a state equal (by encoding) to the one recorded, else schedules one `replaceState` 500 ms after the last change. `exampleLoaded` (one function for an example and a catalogue entry) records the state, cancels a pending burst and calls `pushState` at once. The query keeps every parameter that is not a codec key of a registered instance (another script's keys, and keys of instances not on the page), then appends each changed instance's keys (instances in id order); `pathname` and `hash` are kept. `linkFor(id)` is `location.origin` plus that URL, built now; `copyLink(id, clipboard)` writes it inside `try` and answers a boolean. `replaceState` and `pushState` are inside `try`, refusals swallowed silently. On `popstate` every instance re-reads the URL with `decodeState` against its defaults and its callback receives the state and the notice (plan). Reason: SPEC 7.4, the instruction (5.6).
