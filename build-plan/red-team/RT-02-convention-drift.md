# RT-02: convention-drift

Applies from phase 0. Runs in: a worktree on branch `redteam/P{k}-RT-02`.

Before this file you have read `build-plan/RED-TEAM-COMMON.md` and `build-plan/CONTRACTS.md`. Everything there applies.

## 1. Mission

This lens hunts the errors of convention that the golden tests cannot see: $C$ used where $C^{\mathsf T}$ is meant (row against column, roads into against roads out of), positions printed where labels are meant (E-7), a choice made by drawn order or label instead of by lowest position (E-5), node 0 placed anywhere but first on an affine board, `C2` written where a computed name must say `B2`, and the reversed board forgotten where the specification asks for it (minuscule nodes, fired forms, coroots, the restricted and averaged roots). The golden file is built from symmetric boards (on $A$, $D$, $E$ every transposition is invisible), from labels that start at 1 (where a stray `+ 1` and a correct `toLabels` agree), from the lowest-position play from all ones, and from functions some of which have no golden key at all (`toPopulation` off $E_8$, `coroot`, `separatingRoots`, `symbolicPlay`, `stringThrough`, `level` off the pentagon); a build can pass every gate and still show the reader the dual board, the inverse relabelling or the wrong node. The lens reads the engine and site source with these confusions in mind, builds the smallest asymmetric case on which each confusion changes a value, runs it against the build and the oracle, and checks that a permanent test exists that would fail if the convention were broken. If this lens misses, the Sandbox, the Classification Lab, the Affine Playground and every link on an affine board teach the reader a transposed or renumbered mathematics with green tests.

## 4. Attack list

Each attack names its phases in brackets. "Oracle" means a call through the bridge of section 5; every value quoted below was computed with the committed oracle. Severity: a wrong value on the reader's screen or in an engine result is a **blocker** (a convention violated); a correct value with no test that would fail under the confusion is **major** where the specification names the test (E-7's unit test, the T7 criterion on $B_3$), else **minor**. Attack numbers are fixed identifiers, cited by other files (`agents/P7-overview.md` cites attack 38) and by findings, so they are not renumbered: the list is in order of likelihood, and attacks 39 to 44, added after the first 38 were numbered, sit beside the attacks they rank with (39 after 2, 40 after 6, 42 after 18, 43 after 19, 41 after 22, 44 after 29).

1. **Stray conversions between positions and labels** [0 to 7]. Try: list every place outside `toLabels` and `toPositions` that adds or subtracts one to or from a node index, or indexes `labels` by hand. How: the grep commands of section 5 over `packages/engine/src`, `packages/engine/test`, `site/src` and `site/tests`; read every hit in context; for the harness, read `labels` and `wordLabels` in `packages/engine/test/golden/_harness.ts` and confirm they call `toLabels(board, ...)` rather than `p + 1`. Standard: E-7, "Two functions, `toLabels` and `toPositions`, convert node lists and words; nothing else converts"; CONTRACTS 3 (the harness helpers). Finding: any `+ 1` or `- 1` applied to a node, a word, an `onAct` argument, a `data-node`, an announcement number, a URL label or a golden comparison; quote the line and give the affine board (phase 2 and later: `B3~`, labels `[0, 1, 2, 3]`) on which it prints the wrong node. A harness helper written as `p + 1` is a blocker from phase 2, because every golden test that converts nodes on an affine board then passes for the wrong reason.

```python
#!/usr/bin/env python3
"""ask.py <reference dir> <request.json>: calls one lie_games function and prints the result as JSON.
request.json: {"fn": "coroot_coords", "args": [[[2,-1,0],[-1,2,-1],[0,-2,2]], [1,2,2]], "kwargs": {}}
Special arguments: {"$cartan": ["B", 3]} is lie_games.cartan("B", 3); {"$T": M} is the transpose of M;
{"$affine": ["B", 3, false]} is the matrix of affine_extension(cartan("B", 3), short=false)."""
import sys, json, os
from fractions import Fraction
sys.path.insert(0, os.path.abspath(sys.argv[1]))
import lie_games as lg  # noqa: E402

def dec(x):
    if isinstance(x, dict):
        if '$cartan' in x: return lg.cartan(*x['$cartan'])
        if '$T' in x: return lg.transpose(dec(x['$T']))
        if '$affine' in x:
            L, n, short = x['$affine']
            return lg.affine_extension(lg.cartan(L, n), short=short)[0]
        return {k: dec(v) for k, v in x.items()}
    if isinstance(x, list): return [dec(v) for v in x]
    return x

def enc(x):
    if isinstance(x, Fraction): return str(x.numerator) if x.denominator == 1 else f"{x.numerator}/{x.denominator}"
    if isinstance(x, (list, tuple)): return [enc(v) for v in x]
    if isinstance(x, dict): return {str(k): enc(v) for k, v in x.items()}
    return x

req = json.load(open(sys.argv[2]))
print(json.dumps(enc(getattr(lg, req['fn'])(*dec(req.get('args', [])), **dec(req.get('kwargs', {}))))))
```
