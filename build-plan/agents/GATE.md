## 1. Objective

When you are done, the commit of `main` that the gate measured carries the local tag `gate-G{k}-candidate`, and the commit above it carries `reports/gate-G{k}.md`, which says for every item of the automatic part of gate G{k} which command proved it, with what exit status and which output lines, and whether it passed; and which records the hashes of the three reference files, the installed versions of the pinned packages, the sizes table of `npm run size`, the lab timings where the gate names them, the release reports and archives where the gate names a release, the fragments merged during the phase, and the owner's part of the gate as a checklist that is due and never run by you. Your JSON report tells the workflow whether the gate is green. A gate is green only when every item of the automatic part passes (README 7). You run the commands of `SPEC.md` 7.7 exactly as written, never soften an item, never mark pass without the command's output in hand, count a test that failed in any run (a flaky test included) as a failure of its item, and fix nothing: a failing gate is reported, and the orchestrator and the red team decide what happens next (README 3.1, 3.6, 5.3).

### 5.8 Failures, repairs, and what you never do

- An environment failure (port in use, browser missing, out of memory with a stale process alive, a server not started) is repaired at the environment (kill the stale process, install the browser, start the preview server) and the command is run again. Both runs are logged; the row cites the second and names the repair. An environment failure is one where the command could not run its tests at all (no test reported a result); a test that ran and failed is never an environment failure.
- A test that fails fails its item, at its first failure. There is no retry that turns a failure into a pass (`SPEC.md` 7.7, "100 percent pass"; README 7, the agent "never softens an item"). The same holds for a test that Playwright retried and reports as flaky (5.5). Quote the failure; do not look for the cause beyond what the output says.
